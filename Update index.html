GitDigital‑ZK — Ecosystem Release Notes v1.0.0

Official v1.0.0 launch of the GitDigital‑ZK privacy, identity, and cryptography stack: Aurora‑zk, zk‑Mask, zk‑Authorship, AI Gateway, and orchestration apps.
Release Date: May 2026 Status: Stable — Production Ready Scope: zk‑Cryptography • zk‑Identity • AI Gateway • Orchestrators • Payment Rails

Overview

Version 1.0.0 marks the official launch of the GitDigital‑ZK ecosystem — a unified suite of zero‑knowledge cryptography tools, identity frameworks, AI gateways, and zk‑powered automation apps.

This release establishes:

  • A zk‑native cryptography framework (Aurora‑zk)
  • A zk‑identity and authorship verification layer
  • A zk‑masking + phone activation privacy stack
  • An AI Gateway for Ollama‑powered inference
  • A zk‑orchestrator app for automation
  • Integrated payment rails (Cash App + PayPal)

This is the first complete zk‑stack release under the GitDigital‑ZK organization.

Included repositories in v1.0.0

1. Aurora‑zk‑Cryptography‑Framework Core Cryptography Engine
Repo: https://github.com/GitDigital-ZK/Aurora-zk-cryptography-framework

Purpose: The core cryptography engine powering all GitDigital‑ZK products.

v1.0.0 Features

  • Modular zk‑SNARK/zk‑STARK abstraction layer
  • Proof generation + verification pipeline
  • Hashing, masking, and identity‑safe primitives
  • Developer‑ready cryptography SDK
  • Integration hooks for zk‑Identity, zk‑Mask, zk‑Authorship
2. ZK‑Phone‑Activate‑Mask Phone Privacy Stack
Repo: https://github.com/GitDigital-ZK/ZK-Phone-Activate-mask

Purpose: A privacy‑preserving phone activation + masking system.

v1.0.0 Features

  • zk‑masked phone verification
  • Zero‑knowledge activation proofs
  • Anti‑fraud masking layer
  • API endpoints for mobile onboarding
  • Integrates with zk‑Identity Vault
3. zk‑Authorship‑License Authorship & Licensing
Repo: https://github.com/GitDigital-ZK/zk-authorship-license

Purpose: A zk‑powered authorship and licensing engine for creators, developers, and AI‑generated content.

v1.0.0 Features

  • zk‑proof of authorship
  • zk‑license issuance + verification
  • Immutable authorship registry
  • API for apps, creators, and AI agents
  • GitHub‑native integration for commit authorship
4. AI‑Gateway‑Ollama AI Gateway
Repo: https://github.com/GitDigital-ZK/AI-Gateway-Ollama

Repo: https://github.com/GitDigital-ZK/ZK-Mask-Orgestraror-app
